# RestTimer — таймер отдыха для Apple Watch

Персональное watchOS-приложение: считает отдых между подходами в зале.
Только для себя, без App Store, подпись бесплатным Apple ID (Personal Team).

## Что делает

**Стартовый экран**

- Две карточки — «Подходы» (1–10) и «Отдых» (0:30–5:00, шаг 15 сек). Digital Crown
  крутит значение карточки в фокусе (тап переносит фокус, активная подсвечена
  зелёным), рядом кнопки −/+. Последние значения запоминаются (`@AppStorage`).
- Кнопка СТАРТ, под ней пресеты 4×2:00 / 4×1:30 / 5×2:00 — тап применяет и сразу
  стартует.
- Если уведомления запрещены — предупреждение (без них не будет вибрации при
  опущенной руке).

**Тренировка**

- Цикл: закончил подход (тап или Double Tap) → пошёл отдых → вибрация → следующий
  подход. Сверху капсулы-сегменты прогресса тренировки, по центру счётчик
  «подход x/y».
- Фаза видна боковым зрением: работа — зелёный фон, отдых — оранжевый
  (мягкий градиент в тон фазы).
- Отдых: гигантские системные цифры по центру (тикают даже в always-on), внизу
  полоса-капсула «сгорает» к нулю.
- В тусклом always-on остаются только цифры и счётчик.

**Управление**

- Double Tap (сжать пальцы, Ultra 2) — главное действие текущего экрана:
  закончить подход / пропустить отдых / завершить.
- Колесо во время отдыха — ±15 сек к текущему отдыху на лету.
- Свайп на экране работы — поправить номер текущего подхода (если часть сделана
  вне аппа).
- Долгий тап → меню: Water Lock (защита от случайных касаний) и досрочное
  завершение.
- Каждый управляющий тап отвечает тактильным кликом.

**Вибрация**

- За 10 сек до конца отдыха — предупреждение, в ноль — серия из трёх.
- При опущенной руке (апп заморожен) вибрируют запланированные локальные
  уведомления; когда апп активен — вибрирует сам, баннеры глушатся; после
  пробуждения состояние догоняется без повторной вибры.

**Финал и циферблат**

- Экран «Готово»: галочка и число подходов (с правильным склонением), Double Tap
  завершает.
- Компликация-кнопка на циферблате (голубой штангист) — тап открывает апп.
- Иконка — белый штангист на голубом градиенте.

## Как устроено

| Часть | Файл |
|---|---|
| Точка входа, notification delegate | `RestTimer/RestTimerApp.swift` |
| Машина состояний (working → resting → finished) | `RestTimer/Model/WorkoutModel.swift` |
| Вибрация при опущенной руке (локальные уведомления) | `RestTimer/Model/NotificationManager.swift` |
| Экран настройки | `RestTimer/Views/SetupView.swift` |
| Экран сессии (работа/отдых/финиш) | `RestTimer/Views/SessionView.swift` |
| Компликация (WidgetKit) | `RestTimerComplication/ComplicationWidget.swift` |

Ключевые решения:

- **Своей workout-сессии нет** — параллельно живёт родное приложение
  «Тренировка» (пульс, кольца). Система разрешает только одну активную
  workout-сессию, поэтому наш апп работает поверх, как вспомогательный.
- **Таймер на экране** тикает даже в always-on: цифры — системный
  `Text(timerInterval:)`, его обновляет система при замороженном аппе.
  Полосу-капсулу отдыха рисует сам апп (`TimelineView`), поэтому в тусклом
  AOD она гаснет, а цифры остаются.
- **Вибрация с опущенной рукой** — запланированные локальные уведомления
  (апп в этот момент suspended и сам вибрировать не может). Когда апп
  действительно активен, delegate гасит баннеры и апп вибрирует сам через
  `WKInterfaceDevice` (дедлайн-таск в SessionView, без поллинга); в always-on
  (frontmost, но inactive) delegate пропускает системную вибрацию уведомления —
  глушить её там нельзя, она единственная. После пробуждения `catchUp()`
  догоняет состояние молча, чтобы не дублировать уже отыгравшие вибрации.
- Проект в современном формате (objectVersion 77, synchronized folders) —
  новые файлы в папках подхватываются Xcode без правки project.pbxproj.

## Требования

- Apple Watch c watchOS 11+ (писалось под Ultra 2 / watchOS 26)
- Спаренный iPhone
- Mac с Xcode 26+
- Бесплатный Apple ID, добавленный в Xcode (Settings → Accounts)

## Первая установка

1. Включить Режим разработчика: на iPhone и на часах
   (Настройки → Конфиденциальность и безопасность → Режим разработчика).
2. Открыть `RestTimer.xcodeproj` в Xcode.
3. В Signing & Capabilities выбрать свою Personal Team для **обоих** таргетов
   (RestTimer и RestTimerComplication).
4. iPhone подключить кабелем к маку. В списке устройств выбрать часы
   (появляются через спаренный iPhone), нажать Run (⌘R).
   Первая установка по воздуху — несколько минут, это норма.
5. На часах разрешить уведомления при первом запуске.
6. Разовая настройка на часах: Настройки → Основные → Возврат к циферблату →
   для RestTimer выбрать «Через 1 час» — чтобы апп не сворачивался в зале.
7. Добавить компликацию на циферблат: долгий тап по циферблату → Изменить →
   выбрать слот → Rest Timer.

## Переподпись раз в 7 дней

Бесплатная подпись живёт 7 дней. Когда апп перестаёт запускаться:
iPhone кабелем к маку → открыть проект → Run (⌘R). Две минуты.

## Известные ограничения / план Б

- Надёжность вибрации уведомлениями поверх активной workout-сессии
  проверяется полевым тестом. План Б — smart-alarm-сессия
  (`WKExtendedRuntimeSession`) с повторяющейся вибрацией.
- «Возврат к циферблату» держит апп на экране максимум 1 час
  (лимит watchOS для приложений без своей сессии).

## Статус

Собирается (Xcode 26.6), полный цикл проверен в симуляторе Ultra 3 / watchOS 26.5:
настройка → подход → отдых → автопереход по концу отдыха → скип → «Готово».
Не проверено на реальных часах: вибрация уведомлениями поверх активной
workout-сессии, компликация на циферблате, поведение в always-on, а также
жесты живого устройства — Double Tap и Water Lock (в симуляторе не воспроизводятся).
